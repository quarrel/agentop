 # Codex schema catalogue

This directory stores immutable schema bundles generated by exact Codex CLI
versions. Runtime lookup uses the exact `session_meta.payload.cli_version`;
there is no nearest-version fallback.

Each capture is stored at `codex/<cli_version>/` with this layout:

```text
manifest.json
app-server/
  stable/
  experimental/
internal/
  RolloutLine.json
```

Each manifest records generated filenames and raw SHA-256 hashes plus the
canonical JSON SHA-256 of `internal/RolloutLine.json`. Generated schema files
are preserved unchanged after capture or extraction.

## Local generator capture

Run the installed CLI capture from anywhere in the checkout:

```bash
scripts/capture-codex-schemas.sh
```

The script records the raw `codex --version` output, parsed CLI version and
generator invocations. It generates into a fresh repository-local staging
directory, checks that the producer version is unchanged, verifies the JSON
schemas and expected rollout schema, and atomically publishes the bundle. Set
`CODEX_BIN` only when deliberately capturing with another exact Codex binary.

## Official release-export import

The historical `0.149.0-alpha.4.1` archive is reproducibly imported with:

```bash
scripts/import-codex-release-schemas.sh
```

The importer accepts only the pinned official OpenAI tag object, peeled commit
and release-export bundle hashes. Its manifest records that provenance. It
extracts stable and experimental app-server schemas and the stable internal
`RolloutLine.json`; it does not claim an experimental internal schema.

Both scripts use fresh staging and atomic publication. An existing target is
accepted only when it is byte-for-byte identical; it is never overwritten.
